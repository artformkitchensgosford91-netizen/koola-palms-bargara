# Koola Palms Bargara Beach website prototype

This is a responsive static website for **Koola Palms Apartment 101 at Koola Beach Apartments, Bargara**.

## What is already built

- Premium single-page design, mobile responsive
- Clear Apartment 101 / Koola Palms positioning
- Direct booking and Booking.com calls to action
- Guidance to choose the Superior Apartment category
- Walkthrough video feature using the uploaded Koola Palms cover image
- Apartment features, Bargara experiences, review summary, contact details
- SEO title/description and LodgingBusiness structured data
- Existing Koola Palms logo assets included

## Before publishing

1. Replace the gallery placeholder panels with the final high-resolution property photos.
2. Add the walkthrough video URL in `assets/site.js` where `walkthroughUrl` is declared.
3. Confirm the correct direct-booking URL. The current prototype uses the booking URL linked from the existing Koola Beach website.
4. Confirm whether Booking.com should say `Superior Apartment`, `One-Bedroom Superior Apartment`, and/or `Two-Bedroom Superior Apartment` before launch.
5. Add analytics / Meta Pixel if required.
6. Add final privacy policy / terms if collecting enquiries or tracking users.

## Deploy

Upload the whole folder to any static host or your website server. `index.html` is the homepage.
